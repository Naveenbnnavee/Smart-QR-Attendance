Multi-Layer Defenses

Anti-Proxy Triple Validation Protocol

Layer 1: Temporal Token Rotation

Lecturer screen generates a new signed cryptographic payload every 5 seconds. If a student takes a photo or screenshot and sends it over WhatsApp/Telegram, the token expires before the recipient can scan it.

Layer 2: Real-Time Geo-Polygon

Student scan device transmits browser coordinates with GPS timestamp. Server evaluates Haversine distance formula against session bounding box with 10m tolerance. Scanning from a dorm or outside triggers automatic refusal.

Layer 3: Hardware Signature Lock

Enrolls user device hash (screen dimensions, WebGL vendor, canvas signature). Attempts to sign in with another student's account on the same physical smartphone are flagged as proxy impersonation.

# 3. Configure environment variables (.env)
cp .env.example .env
# 4. Start local development server
npm start
