Multi-Layer Defense Pipeline

Comprehensive security mechanisms engineered to guarantee authentic, tamper-proof attendance recording.

🔄

Temporal Nonce Rotation

Faculty consoles project dynamic QR codes that refresh every 5 seconds. Each token carries an HMAC signature that is invalidated immediately upon expiration.

📍

Haversine Spatial Validation

Calculates precise distance between student GPS coordinates and the lecturer hall perimeter, automatically rejecting scans executed outside the permitted radius.

📷

Facial Biometric Matching

Integrates Face-API.js neural models to extract 128-dimensional facial embeddings, confirming student identity before marking attendance status.

📱

Device Fingerprint Binding

Hardware characteristics and browser signatures are locked to a single student profile, preventing one phone from submitting attendance for multiple peers.

📩

Real-Time Twilio SMS

Dispatches instantaneous confirmation SMS alerts directly to the registered student/guardian mobile number upon successful verification.

📊

Faculty Analytics & Export

Equips teachers with real-time class attendance dashboards, live verification logs, percentage tracking, and one-click session reports.
