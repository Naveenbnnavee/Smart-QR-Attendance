Protocol Specification

Triple-Layer Anti-Proxy Pipeline

Atomic Validation
DEFENSE LAYER 01

Temporal Nonce Rotation

The lecturer's screen regenerates a cryptographically signed HMAC token every 5 seconds. If an absent student receives a photo or screenshot via WhatsApp or Telegram, the token has already expired before the scan completes.

DEFENSE LAYER 02

Haversine Spatial Bounding

The scanner client transmits high-accuracy browser GPS coordinates. The server evaluates the spherical distance between the active lecture hall coordinates and student coordinates with a strict 10-meter boundary threshold.

DEFENSE LAYER 03

Hardware Fingerprint Lock

On first enrollment, a unique client fingerprint (WebGL GPU string, screen depth, canvas render hash) is locked to the student profile. Attempting to scan for a classmate on the same phone is automatically rejected.
